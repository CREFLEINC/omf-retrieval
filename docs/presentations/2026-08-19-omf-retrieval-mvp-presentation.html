MVP INTENT02

02 · 범위 경계

MVP는 근거 검색 서비스이며, 생성형 답변과 Agent 도구는 2차다

MVP에 포함

  • 지정 Git commit의 승인된 Markdown 색인
  • Parent–Child 분할과 하이브리드 검색
  • REST API·Search CLI·운영자 Admin CLI
  • 근거 패키지, 품질·성능 평가, 롤백

2차 개발로 분리

  • LLM 요약·분석·답변 생성
  • 대화형 Agent·MCP·function tool
  • 리랭커·ANN·검색 확장
  • 자동 백업·중앙 관측·Git 전체 이력 검색

검색 원본: OMF 저장소는 읽기 전용이며, 검색 플랫폼과 릴리스 주기를 분리한다.

INDEXING05

05 · 문서 분할

Child로 정확히 찾고 Parent로 맥락을 전달한다

Parent(상위 절)–Child(검색 단위) 구조는 제목 계층과 원문 행 범위를 함께 보존한다

Parent · 제목이 있는 상위 절요청 시 최대 1,200 tokens 문맥 제공
Child A작은 절은 600 tokens 이하 단일 단위
Child B긴 절은 목표 400 · soft max 600
Child C표·목록·인용은 경계 보존 · 최대 800
검색문 구성: 모든 child 앞에 제목 계층을 포함하고, 검색 결과에는 원본 child의 개별 행 범위와 점수를 남긴다.
PARENT–CHILD06

06 · 하이브리드 검색

식별자와 의미를 각각 찾고 RRF로 순위를 결합한다

RRF(Reciprocal Rank Fusion, 역순위 결합)는 두 검색기의 순위를 같은 가중치로 합친다

질의·필터권한·버전·경로를 후보 전에 적용
→
pg_trgm키워드 Top 50
pgvectorcosine 정확 검색 Top 50
→
RRFk=60 · weight 1.0 + 1.0
→
Evidencechild 병합 · parent grouping

정확 검색

초기 코퍼스는 ANN 인덱스 없이 시작

순위

evidence는 포함 child의 최고 RRF로 결정

보존

keyword·vector 개별 순위와 RRF 점수 반환

추론 경계
